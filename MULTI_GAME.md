# Multi-game build

`build/dinput8.dll` contains the XInput/native-DS4 DirectInput adapter and platform hooks. The DLL selects the config filename from the game executable. It is installed for:

- `Shin Sangokumusou 3\game` — 真三3 / Dynasty Warriors 4: Hyper (DW4 Hyper), reads `SSM3_Tweaks.ini`; four independent D-pad buttons and no left-stick movement bridge. The game keeps its own 1280x960 backbuffer and the borderless window upscales it; all resolution overrides are refused for this build.
- `Shin Sangokumusou 4` — 真三4 Special / Dynasty Warriors 5 Special (DW5 Special), reads `SSM4_Tweaks.ini`; four independent D-pad buttons and a signature-verified native menu map. Same refusal: original render target only, no desktop-sized backbuffer, no perspective rewrite.

`build/dinput8-platform.dll` contains platform hooks and is installed in `Dynasty Warriors 8` (真三国无双7). `Launch.exe` reads `SSM7_Tweaks.ini`; it uses one primary-chain Present so overlay frame counts stay aligned. Larger-than-desktop internal buffers remain intact and the windowed runtime scales them to the desktop. This ports the config-driven width/height rewrite behavior of SM6 DX's `resolution_for_SM6TC.dll`, using 110 separately verified `Launch.exe` sites; the SM6TC offsets are not reused. `internal_render_width` / `internal_render_height` set the engine's render size. Battle camera and HUD viewport width profiles are included. `camera_distance_percent` (50–300; 100=original) moves the 3D viewpoint, reloads from the INI while running, and preserves FOV/HUD scale. Foreground shortcuts default to Ctrl+Alt+PageUp/PageDown (farther/nearer), Ctrl+Alt+Home (100%); keys and step are configurable and adjustments save automatically.

`Dynasty Warriors 7 DX` (真三国无双6 with 猛将传 DX) uses `build/dinput8.dll` and `SSM6_Tweaks.ini` for `SM6TC.exe`, `SM6EN.exe`, and `SM6JP.exe`. The profile enables XInput/native-DS4 adaptation, independent D-pad buttons/POV, hot-plug, borderless display, and single primary-chain presentation with desktop scaling. D-pad-to-left-stick mirroring is disabled so it cannot move the character; the game's independent menu map is not confirmed, so D-pad menu navigation may need further work. For `SM6TC.exe` only, the installer also installs the supplied `d3dx9_43.dll` mod loader with `Fix_for_SM6.dll` and `resolution_for_SM6TC.dll` in `mods`. XInputPlus proxy DLLs are omitted because the main `dinput8.dll` already owns DirectInput/XInput adaptation. `install-ssm6dx.ps1` makes a timestamped backup; see `THIRD_PARTY_MODS.md` for details.

`OROCHI_Z_TC.exe` (无双蛇魔Z) uses `OrochiZPadX.ini`. Its verified engine size getters and runtime dimensions port the configurable resolution behavior independently of desktop output; the SM6TC offset list is not applied to this different executable. 3840x2160 rendering uses the game primary swapchain for desktop presentation, with a correction for GS sprite Y coordinate overflow above 2048 pixels. Full-screen background depth writes are isolated so preparation maps and result UI retain depth testing. Player battle cameras support the same distance percentage and foreground shortcuts as SSM7; CPU and renderer projections stay synchronized, and preparation maps are excluded. Set both resolution values to 0 for the previous render sizing behavior.

`Sengoku Musou 2` uses `build/dinput8.dll` and `SM2_Tweaks.ini`. It has XInput/native-DS4 adaptation, four independent D-pad buttons and POV (no left-stick movement bridge), close-confirmation removal, and 75 FPS pacing. The available log confirms D-pad states are sent while left-stick axes remain centered; no native menu-map patch is available yet, so menu cursor navigation is not claimed. Its resolution port uses a game-specific in-memory patch that waits for the protected executable to decrypt, replaces its width/height getters, and adjusts HUD/menu geometry; `0/0` follows the active display's physical resolution. The 2.28 DLL and config are installed, but this new resolution path has not yet been confirmed in a live SW2 session; `SM2Resolution.log` will report whether each signature was found.

## D-pad support status

Independent D-pad button output (Buttons 13–16) and POV output are provided by the virtual DirectInput adapter for Orochi Z, 真三3 / DW4 Hyper, 真三4 / DW5 Special, 真三6 DX, and SW2. The left-stick bridge is disabled for all of these profiles, including 真三6 DX. Menu navigation and in-game rebinding depend on each game's own input map and are not guaranteed by exposing buttons alone. Orochi Z's menu navigation, independent binding, and lack of battle movement were user-confirmed. 真三4 / DW5 Special's menu-map patch is present in runtime logs, but in-game confirmation is not recorded. 真三3 / DW4 Hyper's menu-map selector is in code, but its latest available runtime log predates it. SW2's D-pad output is confirmed while its menu map is still unavailable. 真三7 / Dynasty Warriors 8's platform-only DLL does not provide this controller adapter. Therefore it is not accurate to say every title currently has confirmed D-pad cursor navigation and independent rebinding.

Run `build.cmd` and `build-platform.cmd` from a Visual Studio x86 developer environment to rebuild both variants. `install-targets.ps1` installs only the compatible targets and creates timestamped backups with `manifest.json`.
